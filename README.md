# Удмурт кыл — учим удмуртский

**Сайт:** https://depthd.github.io/udmurt/

Бесплатный тренажёр удмуртского языка в духе Duolingo для студентов: короткие уроки по 3–5 минут,
повторение по интервальной схеме (FSRS), словарь на 38 842 слова, 4 896 фраз с переводом,
раздел о языке и каталог всех найденных материалов. Работает с телефона, без регистрации,
прогресс хранится в браузере.

| Раздел | Что внутри |
|---|---|
| Учиться | Путь уроков. Юнит 1 «Знакомство» — 7 уроков: приветствия, «меня зовут», «я студент», «я из Глазова», возраст, учёба, история-диалог. У юнита есть шпаргалка |
| Повторять | Повторение слов по расписанию, «работа над ошибками», разминка |
| О языке | Родство, история, носители, диалекты, Глазов, алфавит, грамматика, сравнение с финским, венгерским, коми и другими |
| Словарь | Поиск в обе стороны без учёта ӧ/ӥ/ӟ/ӝ/ӵ, значения из Викисловаря, примеры из Tatoeba |
| Материалы | 70 учебников, словарей, курсов, каналов, книг — с пометкой о правах |
| Профиль | Серия дней, XP, календарь, достижения, настройки, перенос прогресса кодом |

## Язык — только проверенный

Каждое удмуртское слово в уроках имеет источник (Tatoeba, учебники УдГУ, грамматика Алатырева, словари)
и статус: `sourced` — «из источника, ждёт проверки носителем», `verified` — «проверено носителем».
Черновики (`draft`) в уроки не попадают — это проверяет автоматический тест. Машинный перевод не используется.

Нашли ошибку — нажмите «⚑ Сообщить об ошибке» под ответом в уроке или
[создайте заявку](https://github.com/depthd/udmurt/issues/new).

## Для разработчиков

```bash
npm ci
npm run dev          # http://localhost:5173/udmurt/
npm test             # проверка контента + unit-тесты
npm run check        # типы
npm run test:e2e     # Playwright: прохождение всех уроков
npm run build
```

Стек: Svelte 5, TypeScript, Vite 8. Контент — YAML в `content/`, проверяется схемой (`src/lib/content/schema.ts`).
Деплой — GitHub Actions → GitHub Pages при каждом пуше. План и критерии — [PLAN.md](PLAN.md),
исследования — [docs/research/](docs/research/).
