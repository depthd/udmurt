# Удмурт кыл — учим удмуртский

**Сайт:** https://depthd.github.io/udmurt/

Бесплатный тренажёр удмуртского языка в духе Duolingo для студентов: короткие уроки по 3–5 минут,
повторение по интервальной схеме (FSRS), словарь на 38 842 статьи, 4 896 фраз с переводом,
раздел о языке и каталог всех найденных материалов. Работает с телефона, без регистрации,
прогресс хранится в браузере.

| Раздел | Что внутри |
|---|---|
| Учиться | Путь из 11 юнитов, 67 уроков: знакомство, числа, семья, глаголы, еда, город, дни недели, прошедшее и будущее время, прилагательные, «на паре». У каждого юнита — шпаргалка. Уроки открываются по порядку, но урок, заданный в группе, можно открыть сразу |
| Повторять | Повторение слов по расписанию, «работа над ошибками», разминка, игра «5 букв» |
| Читалка | 10 коротких текстов: нажмите на слово — значение и разбор; вопросы после текста |
| Разговорник | 341 слово и фраза курса по юнитам (266 с озвучкой) и все шпаргалки; печать юнита на листок |
| О языке | Родство, история, носители, диалекты, Глазов, алфавит, грамматика, сравнение с финским, венгерским, коми и другими |
| Словарь | Поиск в обе стороны без учёта ӧ/ӥ/ӟ/ӝ/ӵ, значения из Викисловаря, примеры из Tatoeba |
| Материалы | 70 учебников, словарей, курсов, каналов, книг — с пометкой о правах |
| Группа | Недельная лига по кодам (без сервера и регистрации), режим проектора для пары |
| Помочь проекту | Носитель проверяет фразы и записывает их голосом — получается архив для проекта |
| Профиль | Серия дней, XP, календарь, достижения, настройки, перенос прогресса кодом |

## Язык — только проверенный

Каждое удмуртское слово в уроках имеет источник (Tatoeba, учебники УдГУ, грамматика Алатырева, словари)
и статус: `sourced` — «из источника, ждёт проверки носителем», `verified` — «проверено носителем».
Черновики (`draft`) в уроки не попадают — это проверяет автоматический тест. Машинный перевод не используется.

Нашли ошибку — нажмите «⚑ Сообщить об ошибке» под ответом в уроке или
[создайте заявку](https://github.com/depthd/udmurt/issues/new). Нет аккаунта на GitHub — там же можно
скопировать текст и отправить его преподавателю.

## Для разработчиков

```bash
npm ci
npm run dev          # http://localhost:5173/udmurt/
npm test             # проверка контента + unit-тесты
npm run check        # типы
npm run test:e2e     # Playwright: все уроки, читалка, офлайн, битые ссылки и данные
npm run build
```

Надёжность и безопасность (подробнее — в комментариях `vite/build-plugins.ts`, `src/lib/safe.ts`, `public/sw.js`):

- данные из браузера, коды прогресса и группы проверяются по полям — испорченные данные не роняют сайт;
- если раздел всё же сломался, вместо пустого экрана — «Что-то пошло не так» с кнопками «Обновить» и «Сбросить»;
- политика безопасности (CSP) разрешает только свои скрипты; чужой `<script>` не выполнится;
- офлайн: service worker заранее сохраняет все файлы сборки, аудио отдаёт кусками (как просит Safari);
- e2e-тесты падают при любой ошибке в консоли или нарушении CSP; проект `offline` проверяет боевую сборку без сети.

Стек: Svelte 5, TypeScript, Vite 8. Контент — YAML в `content/`, проверяется схемой (`src/lib/content/schema.ts`).
Деплой — GitHub Actions → GitHub Pages при каждом пуше. План и критерии — [PLAN.md](PLAN.md),
исследования — [docs/research/](docs/research/).
