# Удмурт кыл — план проекта

Сайт-тренажёр удмуртского языка «как Duolingo» для нашей группы.
Живёт на GitHub Pages: **https://depthd.github.io/udmurt/**

Исследования, на которых построен план, лежат в [`docs/research/`](docs/research/):
разбор Duolingo и других приложений, наука об обучении, дизайн, открытые данные, учебные материалы,
факты о языке, проверка первых фраз.

---

## 1. Цель и принципы

**Цель:** чтобы изучать удмуртский было так же легко и затягивающе, как английский в Duolingo:
по 5 минут в день, с телефона, без регистрации, с проверенным языком.

Принципы, проверенные исследованиями (см. отчёты 01 и 03):

1. **Сначала дело, потом регистрация.** Первый урок открывается одной кнопкой, имя спрашиваем после.
2. **Учимся извлечением, а не чтением.** Почти всё — задания на вспоминание: выбор → плитки → ввод.
   Правильный ответ показываем всегда.
3. **Интервальное повторение (FSRS).** Слово не «выучено» с первого раза, к нему возвращаемся
   через растущие интервалы.
4. **Ошибки не наказываются.** Нет сердечек и энергии. Ошибка возвращается в конце урока, тон дружелюбный.
5. **Серия дней (стрик) — за 1 урок в день**, с «заморозками» на пропуски.
6. **Обратная связь мгновенная (< 100 мс):** цвет, звук, вибрация, анимация, разбор слова по морфемам.
7. **Язык — только проверенный.** У каждого слова есть источник и статус. Черновики в уроки не попадают
   (это проверяет автоматический тест). Машинный перевод запрещён.
8. **Чистый визуальный стиль «белый холст + красная нить»** по мотивам удмуртской вышивки и флага.
   Плавные линии, пружинистые анимации, учитываем `prefers-reduced-motion`.

## 4. Критерии приёмки

### Язык и контент
- [ ] У 100 % удмуртских слов и фраз в уроках есть источник и статус `sourced` или `verified`
- [ ] 0 машинных переводов; 0 фраз без источника (проверяется тестом `npm run validate`)
- [ ] Все удмуртские буквы — кириллица в NFC (ӧ — один символ); тест ловит латинские двойники
- [ ] Грамматические пояснения сверены с Алатыревым (1983) и Каракуловыми (2001)
- [ ] Каждая фраза юнита 1 до пометки `verified` проверена носителем или преподавателем — **нужна помощь группы**

### Обучение
- [ ] Урок длится 3–5 минут, в нём 10–16 заданий и 3–6 новых элементов
- [ ] Каждое новое слово в уроке вспоминается 2–3 раза, ошибки возвращаются в конце урока
- [ ] Ответ засчитывается без учёта регистра и пунктуации; пропущенная ӧ/ӥ/ӟ/ӝ/ӵ — «почти» с подсказкой;
      ошибки в окончаниях не прощаются
- [ ] Повторение планирует FSRS, слова с ошибками попадают в «Работу над ошибками»

### Интерфейс и ощущения
- [ ] Отклик на ответ < 100 мс: цвет, иконка ✓/✗, звук, вибрация на Android, анимация
- [ ] Экран итогов: XP с анимацией счёта, точность, время, конфетти-«звёздочки», серия дней
- [ ] Плавные переходы между экранами (View Transitions), путь уроков — гладкая SVG-кривая
- [ ] Всё работает с телефона шириной 320 px, без горизонтальной прокрутки
- [ ] Тёмная тема; переключатели звука, вибрации, анимаций
- [ ] Без анимаций при `prefers-reduced-motion`, обратная связь при этом остаётся

### Доступность и качество
- [ ] Контраст текста ≥ 4.5:1, элементов ≥ 3:1; фокус виден; урок проходится с клавиатуры (Enter, 1–9)
- [ ] Удмуртский текст размечен `lang="udm"`; статусы объявляются через `role="status"`
- [ ] Lighthouse (мобильный): производительность ≥ 90, доступность ≥ 95
- [ ] Первый экран < 150 КБ JS+CSS (gzip), словарь грузится лениво
- [ ] CI зелёный: тесты контента, типы, сборка; e2e-тест проходит урок от начала до конца

### Данные и право
- [ ] Прогресс в браузере + экспорт/импорт кодом; данные не уходят на сервер
- [ ] Открытые данные лежат с лицензиями (MIT, CC BY, CC BY-SA), авторы указаны на странице «Источники»
- [ ] Защищённые книги не копируются — только каталог со ссылками и собственные упражнения по фактам языка

## 5. Как добавлять уроки (для группы)

1. Слова и фразы — в `content/lexicon/*.yaml`: удмуртский, перевод, источник, статус.
2. Уроки — в `content/units/<юнит>/<урок>.yaml`: список заданий, ссылающихся на слова.
3. Если в тексте есть двоеточие с пробелом, `#` или `{name}` внутри списка — возьмите текст в кавычки `'…'`.
4. GitHub сам проверит файлы и опубликует сайт. Если есть ошибка, в Actions будет понятное сообщение:
   какой файл и какое поле.

Подробнее — в [`CONTRIBUTING.md`](CONTRIBUTING.md).

## 6. Риски

| Риск | Что делаем |
|---|---|
| Ошибки в удмуртском | Источник у каждой фразы, сверка со словарями и грамматиками, статус `verified` только после носителя |
| Нет озвучки | Пока без звука; записи носителей — главный приоритет этапа 2 |
| Safari чистит данные через 7 дней | `navigator.storage.persist()`, экспорт кодом, установка как приложение (PWA) |
| Лицензии | Каждый источник лежит в своей папке со своей лицензией, страница «Источники» |
