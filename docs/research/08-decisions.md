# 08. Решения по замечаниям проверки контента (юниты 1–11, читалка)

Протоколы проверяющих: `08-verify-lexicon-u1-3.md`, `08-verify-lexicon-u4-6.md`, `08-verify-lexicon-u7-10.md`,
`08-verify-grammar-u1-5.md`, `08-verify-grammar-u6-10.md`. Каждое замечание перепроверено по источнику перед правкой.
Удмуртский текст фраз не менялся (озвучка осталась прежней) — правились переводы, варианты ответов, разборы,
пояснения, шпаргалки и задания.

## Общие правки (во всех юнитах)

| Замечание | Решение | Почему |
|---|---|---|
| Варианты ответа `[Хорошо, иду.]` режутся YAML по запятой — одна плитка «Хорошо» засчитывалась | Исправлено 6 записей, сборка теперь падает на таких обрывках | Список YAML без кавычек — это два элемента |
| Частица -а и парные слова склеиваются без дефиса («тон студента») | Часть с «-» впереди пишется через дефис (-а, -атай); «но» — отдельное слово | Склейка должна совпадать с орфографией |
| В разборах нет первого слова (мон, тон…), атай + ед ≠ «атаед» | Дописано 20 разборов; ата-ед, ага-е; тест «склейка = текст» | Алатырев § 11: й + е пишется е |
| Обманки «собери слово» видны по цвету | Длинные окончания с «-»; у фраз из слов обманки — слова | Иначе задание решается без языка |
| Слова проверяются раньше, чем показаны | Добавлены карточки, изменены match/type; тест `teach-order` | Иначе слово идёт в повторение как выученное |
| Вопросы «Куда ходил собеседник Даши?» | Вопросы к ученику на «вы» | Реплики ученика подписаны «Вы», мужской род исключал учениц |

## Юниты 1–3

| Замечание | Решение | Почему |
|---|---|---|
| Шпаргалка u3: «мой» после согласной — -ы | **Исправлено**: обычно -э/-е (эше), -ы — у части слов (нылы, выны, нимы) | Алатырев § 33; uniparser: 11 409 основ на -е против 242 на -ы |
| Глазкарысь: разбор Глаз+кар+ысь, обманки дают «Глазысь» | Разбор Глазкар + ысь; note: Глазкар — скорее книжная форма, в речи — Глаз, Кар | Вахрушев с. 554 «Глазов, Кар»; ru.wikipedia, сноска о Глазкар |
| Источники-образцы вместо точных фраз | Добавлены точные Tatoeba: 11732861, 12306042, 12261336, 12156594, 12275677, 12273605, 12341535 | Есть дословные совпадения |
| Порядок слов не принимается | udm_alt: «Тон кытысь?», «Кӧня арес тыныд?», «Тон кытын улӥськод?» | Tatoeba 12273605, 12366284; порядок слов свободный (07 § 11.8) |
| u3-story: плитки собирают «…семьяе вань» | Обманка «вань» → «тынад» | Второй верный ответ |
| Песянай/песятай | note: по отцу; по маме — ӵужанай, ӵужатай | Кыллюкам 2012, Вахрушев |
| Ӟечбуресь с вариантом «Здравствуй!» | Вариант убран | Курс учит: Ӟечбур — на «ты» |
| Ар / арес, -дон / -тон, частица -а, «Мой сын — студент» | Уточнены пояснения | Вахрушев, Алатырев § 37 |
| Заголовки «Кытысь тон?», «Али кӧня час?» | «Тон кытысь?», «Кӧня час?» | Засвидетельствованы в Tatoeba |
| Один «Преподаватель» противоречит себе в u3 | В u3-l4 говорит Анна | Связность историй |
| u2-story: «Сейчас три» → «Приходи в два» | **Оставлено** | Подходящей фразы с более поздним часом нет; приглашение может быть на завтра |
| Объём уроков, «Новое слово» для уже показанных слов в u2-l2, слова без закрепления | **Отложено** | Не ошибки языка; нужна перестройка уроков |

## Юниты 4–6

| Замечание | Решение | Почему |
|---|---|---|
| «со уг» в одном ряду с «-ськы» | Шпаргалка: со уг + основа (Том Австралие уг мыны, Нокин но уг тоды) | Алатырев § 51; Tatoeba 12267575, 11677672 |
| -исько без варианта -ӥсько, 3 л. только -е | Добавлено правило ӥ и -э | Алатырев, орфография |
| Fill с выбором знака препинания | Заменён на выбор окончания ярат-ӥсько / -ӥськод / -э | Прежний ничего не проверял |
| Порядок слов и местоимение не принимаются | udm_alt: «Мон лыдӟиськыны яратӥсько», «Туннэ мон музее…», «Тон кытчы мынӥськод?», «Лыдӟисько.»; ru_alt «Ты не слушаешь меня» | Tatoeba 12165377, 11732785; курс сам учит опускать местоимение |
| «Хочу чай» без «попить» | ru_alt «Я хочу попить чаю» | Второй перевод Tatoeba 11527889 |
| u6-l5: обманка «дорын» даёт верный ответ | Обманки «вокзалын», «улӥськод» | Вахрушев: дорын «у, около» |
| Пары match «автобус = автобус» | Заменены на пары, требующие знания | Решались без языка |
| «Окончание -онни», «вокзал рядом» | «Суффикс -онни»; «возле вокзала» | Алатырев § 34; Вахрушев |
| Ӟечбуресь у Даши/бабушки на «ты» | Ӟечбур | Курс учит различие |
| Реплика «кунокуаын» без источника | Комментарий с Tatoeba 11759108 | Текст дословно из Tatoeba |

## Юниты 7–10 и читалка

| Замечание | Решение | Почему |
|---|---|---|
| Правило ӥ шире нормы | Только после д, з, л, н, с, т; иначе — и (сиськи) | Алатырев § 6, § 12 |
| «Ӵуказе бере» — не словарное «послезавтра» | **Отклонено**: форма есть у Вахрушева (s.v. бере: «ӵуказе ~ послезавтра»); добавлены ӵуказе улыса и усьсэ | Проверено по OCR Вахрушева |
| Арня «старое значение — воскресенье»; покчиарня «малая неделя» | Второе, живое значение «воскресенье»; покчи — «младший», «младшее/удмуртское воскресенье» | Вахрушев: арня 2, «покчи ~ четверг; удмурт ~ пятница», «зуч ~ воскресенье» |
| Вордӥськон: «второе значение — рождение» | «Рождение» — основное | Вахрушев, Кыллюкам |
| «Куда ходил?» — подходит и «он» | «Куда ты ходил?», «Что ты купил?» | У русского прошедшего нет лица |
| «Не был»: ӧз вал? | С вал всегда ӧй (Со татын ӧй вал) | Алатырев § 66; Tatoeba 12174264 |
| «Уг — не сейчас» для «уг ветлы» | «уг ветлы» — будущее «не пойду» | Таблица спряжения Алатырева |
| Плитки без женских форм | Добавлены «ходила», «проснулась» | Ученица не могла собрать свой ответ |
| «Мар карыны малпаськод?» в разделе будущего | note: это настоящее время | малпаны, II спряжение |
| «Вож яблоко» | «Вож яблок» | dict.json, Tatoeba: яблок |
| «Горд дэрем солы мынэ» («идёт к лицу») | Запись удалена (в уроках не была) | Похоже на кальку; у Вахрушева «идёт (к лицу)» — тупаны |
| Fill «Йыр___ висе на?» — два ответа | ru «У тебя голова ещё болит?» | -ыз «его» тоже подходило |
| Будущее: нет варианта -ё | Добавлен (кылёз) | Алатырев § 12 |
| Жаляса верано «с сожалением сказать» | «жалея, надо сказать» | верано — причастие долженствования |
| Диалоги: «Что у тебя болит?» после ответа; t2: «вы» и «ты» вперемешку; t9 «гость» | Порядок реплик исправлен; в t2 убрана реплика на «вы»; вопрос t9 — к ученику | Связность |
| u10-l3: 10 карточек из 16 | Убраны 2 лишние карточки, добавлен выбор | Новизна ≤ 30–40 % заданий |
