## TL;DR (самое важное)

1. **Главный словарь для нас — `uniparser-grammar-udm` Т. Архангельского (лицензия MIT).** В нём **56 361 лексемная запись** и **54 584 уникальные леммы**. Русский перевод есть почти у всех (у **56 347** записей), английский только у 5 246. Есть парадигмы словоизменения и **частотный список из 359 669 словоформ** по корпусу примерно в 10 млн слов. В соавторах указан сам УдмФИЦ УрО РАН, а лицензия разрешает встраивать данные без ограничений, нужно только сохранить копирайт ([GitHub](https://github.com/timarkh/uniparser-grammar-udm)). Я прогнал готовый пайплайн «частотные словоформы → леммы → русские глоссы»: из 5 000 самых частых словоформ получилось **1 909 лемм с переводом**.
2. **Главный источник предложений — Tatoeba.** Это **4 918 удмуртских предложений**, у **4 896** из них есть русский перевод. Средняя длина — **3,67 слова**, и 3 731 предложение состоит из 2–4 слов, то есть почти идеальный материал для новичков. Лицензия **CC BY 2.0 FR**, нужно указывать автора. Аудио нет: 0 записей ([экспорт](https://downloads.tatoeba.org/exports/per_language/udm/), [условия](https://tatoeba.org/en/terms_of_use)). Там есть почти готовые фразы для первого урока: «Мон студент.», «Мон Венгриысь.» («Я из Венгрии.»), «Мынам нимы Джек.», «Кыӵе курсын тон дышетскиськод?» («На каком курсе ты учишься?»).
3. **Викисловарь — это небольшой, но размеченный слой.** В ru.wiktionary в категории «Удмуртский язык» **1 441 страница**, в en.wiktionary в «Udmurt lemmas» **1 299**. Готовые машиночитаемые выгрузки Kaikki.org есть для обоих разделов (1 433 и 1 321 слово). В них есть IPA (в en у 1 347 записей), таблицы склонения/спряжения и около 160–180 примеров с переводом. **Аудио — 0.** Лицензия **CC BY-SA 4.0 + GFDL**, то есть share-alike: эти данные держим в отдельном файле под той же лицензией.
4. **Universal Dependencies: удмуртского трибанка нет.** В индексе UD v2.18 слово «Udmurt» не встречается ни разу. Там есть коми-зырянский, коми-пермяцкий и древнепермский, а UD_Udmurt-UdT не существует ([universaldependencies.org](https://universaldependencies.org/)).
5. **Mozilla Common Voice: по удмуртскому ноль.** 0 часов, 0 предложений, сбор закрыт (`is_contributable: 0`), локализация 0 %: в репозитории переведено 9 строк ([API](https://commonvoice.mozilla.org/api/v1/stats/languages)). Для запуска нужно ≥75 % локализации интерфейса и **750 предложений** (у удмуртского «Band A») ([LANGUAGE.md](https://github.com/common-voice/common-voice/blob/main/docs/LANGUAGE.md)). Это реальный проект для группы.
6. **Синтез речи есть, и он работает на обычном процессоре.** Я запустил **Meta MMS-TTS `facebook/mms-tts-udm`**: VITS, 36 млн параметров, 145 МБ, 16 кГц, понимает ӝ ӟ ӥ ӧ ӵ без транслитерации. Одна фраза генерируется за **0,15–0,35 с на 4 vCPU**. Обратная проверка распознавателем MMS ASR вернула «мон глазысь» и «мынам нимы алексей» почти дословно, а короткие слова («Тау!») распознались плохо. Лицензия **CC BY-NC 4.0**, только некоммерческое использование ([HF](https://huggingface.co/facebook/mms-tts-udm)).
7. **Silero выпустил удмуртский голос под MIT.** Это `v5_cis_base` / `v5_cis_base_nostress`, диктор **`udm_bogdan`**, файл 91,7 МБ, лицензия MIT ([README](https://github.com/snakers4/silero-models), [LICENSE_CIS](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS)). Старый `v4_cyrillic`, `b_udm` идёт под CC BY-NC(-SA). Сам я Silero **не запускал**: модель — это torch.package со встроенным кодом, а правила запрещают выполнять код из скачанных файлов. Её нужно проверить на слух (Colab-ноутбук `examples_tts_cis.ipynb`).
8. **Машинный перевод русский ↔ удмуртский есть у трёх сервисов.** Это Яндекс.Переводчик ([Udmurt–Russian](https://translate.yandex.com/en/translator/Udmurt-Russian)), Google Translate (удмуртский есть в списке языков) и **TartuNLP** с открытым API. TartuNLP я проверил на 8 фразах: например, «Я учусь в университете.» → «Мон университетын дышетскисько.», «Я из Глазова.» → «Мон Глаз карысь.». Всё это годится только как **черновик для автора**. Импортировать машинный перевод как контент нельзя.
9. **Есть свободный орфографический словарь Hunspell `vorgoron/udmspell` (CC0).** Основной `.dic` содержит **108 376 основ**, есть расширение для LibreOffice ([GitHub](https://github.com/vorgoron/udmspell)). С его помощью в браузере можно отличать опечатку от ошибки и засчитывать «почти верно».
10. **Остальное в основном «смотреть, но не брать».** Корпус udmurt.web-corpora.net (9,57 млн словоупотреблений) работает только как поиск и защищён авторским правом. Параллельный корпус УИИЯЛ/УдГУ на HF (101 833 пары) выложен без лицензии и состоит из художественных переводов. Библия (finugorbib) — CC BY-NC-ND или без лицензии. Glosbe и Forvo без открытой лицензии. Apertium udm-rus заброшен (~150 статей, 2021). GiellaLT `lang-udm` (LGPL-3.0) почти без русских переводов: 16 штук против 10 696 финских.
11. **Записей носителей в открытых базах нет совсем.** Ни в Wiktionary, ни на Commons/Lingua Libre (категории `Lingua_Libre_pronunciation-udm` нет), ни в Tatoeba. Собственные записи группы через Lingua Libre (CC BY-SA) и Tatoeba станут вкладом, которого в мире ещё нет.
12. **План импорта по шагам** — в конце отчёта. Коротко: **Tatoeba → uniparser → Kaikki → udmspell → TTS-аудио с проверкой на слух → udm.wikipedia для чтения**, а параллельно собственные записи и выгрузка их обратно в открытые проекты.

- Уникальных лемм **54 584**. Если убрать имена собственные (тег `PN`, 16 393 записи) и записи «ошибочного написания» (тег `missp`, 594), остаётся **39 064 уникальные пары «лемма + часть речи»**.
- **22 511** записей помечены `rus`, то есть заимствования из русского. По этому тегу легко отделить исконную лексику, а для новичка можно отдельно подсветить «бесплатные» слова вроде «студент» или «школа».
- Формат записи:
  ```
  -lexeme
   lex: студент
   stem: студент.
   gramm: N,rus,anim,hum
   paradigm: Noun-num-consonant
   trans_ru: студент
   trans_en: student
  ```
- `paradigms.txt` (196 КБ) описывает словоизменение, `udm_lexrules_*.txt` даёт дополнительные русские переводы для форм.
- `wordlists/wordlist.csv` — **359 669 словоформ с частотами** по корпусу «примерно в 10 млн слов» (см. README). `wordlist_analyzed.txt` (66 МБ) содержит готовые разборы всех словоформ в XML.

Анализатор не знает форму «мынэсь» (пустой разбор). Это ожидаемо: README заявляет полноту около 96 % на корпусе.

**Пайплайн «частотный словарь для новичков»** (скрипт в scratchpad, проверен): 5 000 самых частых словоформ → **1 909 лемм с русскими глоссами**. Начало списка: со «он/она/оно», но «и», ик «же», та «этот», тӥ «вы», мон «я», ар «год», ас «сам, свой», луыны «бывать; стать», уг «не», удмурт, туж «очень»… гурт «деревня», вераны «говорить», вань «все, всё», ужаны «работать», калык «народ», адями «человек», кулэ «надо», улыны «жить», нылпи «дети», бадӟым «большой», одӥг «один», нунал «день», кыл «язык; слово», кык «два», школа, пичи «маленький».
⚠️ Корпус в основном газетный, поэтому наверх вылезают «ёрос» (район), «кивалтыны» (руководить), «Россия». Частотность — сырьё, а не готовый список. Нужна ручная курация по темам уроков.

**Как импортировать:**
```bash
git clone --depth 1 https://github.com/timarkh/uniparser-grammar-udm
# парсим udm_lexemes_*.txt → data/lexicon/uniparser.json  (lemma, pos, tags, trans_ru, trans_en, paradigm)
# фильтры: убрать gramm ∋ {missp, PN}; для «ядра» брать top-N по wordlists/wordlist.csv
# лемматизация частотника: pip install uniparser-udmurt  →  UdmurtAnalyzer().analyze_words([...])
```
На сайт кладём не весь словарь, а **ядро в 1 000–3 000 лемм**: это ~100–300 КБ JSON (оценка). Морфологию в браузере не запускаем, разборы для слов из наших уроков считаем заранее при сборке.

### 2.2. Викисловарь (ru и en) и выгрузки Kaikki.org 🟡

## 6. Ввод удмуртских букв

- **Свою экранную клавиатуру `ӝ ӟ ӥ ӧ ӵ` (плюс `Ӝ Ӟ Ӥ Ӧ Ӵ`) делаем в любом случае.** Это обязательный элемент упражнений с вводом (см. отчёт 02, п. 6).
- **GiellaLT [keyboard-udm](https://github.com/giellalt/keyboard-udm)** (LGPL-3.0): раскладки для Windows, macOS, Android и iOS через Divvun Installer или Divvun Keyboards. Ссылка на странице помощи.
- **udmurt.info/files:** архивы раскладок Windows (`udmurt_kbd.zip`, `udmurt_alt.zip`), инструкция в PDF и рекомендации по Unicode-шрифтам (Times New Roman/Arial, DejaVu, Charis SIL). Файлы старые, примерно 2000-х годов.
- **Gboard:** есть ли удмуртская раскладка, ⚠️ не подтверждено. Страница справки грузится JS'ом, а WebFetch раскладку не нашёл.
- **Шрифт сайта:** все пять букв — это готовые символы Unicode (U+04DD, U+04DF, U+04E5, U+04E7, U+04F5). Нужен веб-шрифт с ними, и его надо **проверить визуально**. Google Fonts Noto Sans и Inter с кириллическим расширением должны их содержать (⚠️ проверить в отчёте 04 или вёрстке).
- **Нормализация ввода:** в соцсетях пишут без диакритик («сыче» вместо «сыӵе»), об этом прямо говорит README uniparser (режим `nodiacritics`). На сайте засчитываем `о→ӧ`, `и→ӥ`, `ч→ӵ`, `ж→ӝ`, `з→ӟ` как «почти верно» и показываем правильное написание.

## 8. Юридическая схема данных на сайте

1. **Каждый источник лежит в своей папке и со своей лицензией:**
   ```
   data/
     tatoeba/    sentences.json   LICENSE (CC BY 2.0 FR) + у каждой записи author, id
     uniparser/  lexicon.json     LICENSE (MIT, копия оригинала)
     wiktionary/ ru.json en.json  LICENSE (CC BY-SA 4.0) + ссылка на статью
     udmspell/   udm.aff udm.dic  LICENSE (CC0)
     audio/      *.opus           README: «синтез Silero (MIT)» или «Meta MMS (CC BY-NC 4.0)», позже «запись: <имя> (CC BY-SA 4.0)»
     own/        наши фразы       лицензия на выбор группы (рекомендую CC BY-SA 4.0)
   ```
2. **Share-alike не «заражает» весь сайт**, если данные хранятся в отдельных файлах. Но производный JSON, собранный из Викисловаря, сам должен быть под CC BY-SA 4.0. Код сайта можно держать под MIT.
3. **Карточка показывает источник и статус**, например: `Tatoeba #11526026 · kalmez · CC BY 2.0 FR · статус: не проверено носителем`. Это одновременно атрибуция и честность перед учащимися (см. отчёт 02: ошибки в «Удмуртском разговорнике» на RuStore).
4. **Страница «Источники и благодарности»** со всеми лицензиями: Tatoeba, Kaikki/Wiktionary, uniparser (с копирайтом УдмФИЦ), udmspell, Silero/MMS.
5. **Что не брать:** NC-ND (Библия), датасеты без лицензии (УИИЯЛ-корпус на HF, zerpal, lingtrain), Glosbe, Forvo и выдачу корпусов.
