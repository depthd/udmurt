# Решения по редизайну

- В `origin` нет `main`. Основа ветки — текущий `origin/HEAD`, `claude/hopeful-fermat-s2s1vs` (`2a05ad5`).
- Дополнительный лист поз виден в сообщении, но отдельного PNG в рабочем каталоге и архиве нет. Используем прозрачные WebP из пакета по §4.
- В §7 для экранов указан приоритет 4 → 6 → 5 → 3. Коммиты экранов идут в этом порядке.
- У вернувшегося на ширине 360–479 px портрет в приветствии, от 480 px — в карточке продолжения. Это соблюдает лимит одного персонажа из §4.
- Исходные `npm ci`, `check`, `build` успешны. При параллельном запуске `npm test` прошло 217/220: тайм-аут импорта прогресса, последующее состояние прогресса и порог скорости словаря. Итоги повторного прогона и e2e — в отчёте.
- В онбординге девушка показывает первый шаг, птица — второй. На каждом шаге один персонаж.
- Активная навигация сохраняет тёмно-красную заливку и белую подпись в обеих темах. Для обычных кнопок в тёмной теме применяется светло-красная заливка с тёмной подписью из ТЗ.
- На 320 px кнопка шпаргалки стоит рядом с номером, а заголовок и описание баннера занимают всю ширину. Это сохраняет первый юнит в кадре при автопрокрутке пути.
