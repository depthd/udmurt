# Как добавлять слова и уроки

Всё можно делать прямо на сайте GitHub, без программ: откройте файл → карандаш ✏️ «Edit» → внесите правки →
«Commit changes». Через 1–2 минуты сайт обновится сам. Если в файле ошибка, GitHub покажет красный крестик ❌
во вкладке **Actions** с понятным сообщением: какой файл и какое поле.

## 1. Слово или фраза — в словник

Файлы `content/lexicon/*.yaml`. Пример записи:

```yaml
  - id: mon-student            # латиница, цифры, дефис; уникальный
    udm: Мон студент.          # удмуртский текст (буквы ӝ ӟ ӥ ӧ ӵ — кириллицей)
    ru: Я студент.             # перевод
    ru_alt: [Я студентка.]     # другие верные переводы (необязательно)
    udm_alt: []                # другие верные удмуртские варианты (необязательно)
    kind: phrase               # word | phrase | pattern
    emoji: 🎓                  # картинка-эмодзи (необязательно)
    morphemes:                 # разбор по частям (необязательно)
      - { form: мон, meaning: 'я', kind: word }
    note: 'Подсказка, которая покажется в карточке.'
    status: sourced            # sourced — из источника; verified — проверил носитель; draft — черновик
    sources: [{ id: tatoeba, ref: '12345' }]   # обязательно! id — из content/sources.yaml
```

**Правила:**
- без источника слово не принимается; машинный перевод — нельзя;
- `verified` ставит только носитель или преподаватель (напишите в комментарии к правке, кто проверил);
- `{name}` в тексте заменяется именем ученика: `Мынам нимы {name}.`;
- если в тексте есть **двоеточие с пробелом**, `#` или `{name}` внутри `[списка]` — возьмите текст в кавычки `'…'`.

## 2. Урок

Файлы `content/units/<юнит>/<урок>.yaml`, порядок уроков — в `unit.yaml` (поле `lessons`). Пример:

```yaml
id: u1-l3
title: Мон студент
goal: 'Сказать, кто вы'
icon: 🎓
exercises:
  - type: teach                # карточка нового слова
    item: mon-student
  - type: choice               # выбрать перевод
    item: mon-student
    distractors: [mon-name]
  - type: tiles                # собрать фразу из плиток
    item: mon-student
    extra: [тон]               # лишние плитки
  - type: type                 # напечатать перевод
    dir: ru-udm
    item: mon-student
  - type: fill                 # вставить пропуск
    text: Мон студент ___.
    ru: Я не студент.
    options: [ӧвӧл, бен]
    answer: ӧвӧл
  - type: match                # найти пары (3–6 слов)
    items: [ben, ovol, mon]
```

Типы заданий: `teach`, `choice`, `tiles`, `match`, `type`, `fill`, `build` (собрать слово из морфем),
`listen` (нужно аудио), `dialogue` (мини-диалог с вопросом). Все поля — в `src/lib/content/schema.ts`.

Хороший урок: 10–16 заданий, 3–6 новых слов, каждое новое слово встречается 2–3 раза в разных заданиях.

## 3. Материал в каталог

Файл `content/library.yaml` — добавьте запись по образцу соседних. Поле `rights`:
`open` (общественное достояние / открытая лицензия), `free` (бесплатно онлайн), `print` (печатное издание).

## 4. Озвучка

Запишите фразы урока на телефон (тихая комната, по 1 фразе на файл), назовите файлы по `id` слова
(`mon-student.mp3`) и пришлите их в [заявке](https://github.com/depthd/udmurt/issues/new). Укажите, кто говорит
и что вы согласны на публикацию под CC BY 4.0.
